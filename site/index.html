② 直角引号「」 vs 弯引号混排对比

交互对比

弯引号“”属中西文共用码位（U+201C/201D），混排或字体回退时易按西文字体渲染为窄比例字形，导致间距局促；直角引号「」为中日文专属全角码位，与方块字契合且不会退化。

③ 插图简体精修与无损级重压

体积对比

未压缩单卷 EPUB 往往超过 15–20 MB，在手机与电子墨水屏上极易导致翻页和加载卡顿。经无损级算法重压与简体中文精修嵌字后，体积大幅精简且观感依旧锐利。

06 · FAQ

常见问题与说明

本节部分说明由 Chansey 整理，汇总了读者关于底本、校对、引号、图片与阅读器的高频疑问。

哪些番外、联动或特典没有收录？ ▾
本项目定位为某系列主线与外传轻小说 EPUB 档案。跨作品联动（如《某魔法的电脑战机》《某魔法的重装座敷童子》）、店铺附赠的 1–4 页极短篇以及灰村清孝画集 1 附赠《情书争夺战》等少数特典暂未入库（即《S0_00》提示的「X 版有很多没收录的番外内容，这部分请看网翻」）。完整缺口明细与收录边界可查阅仓库中的 全系列作品对应与收录进度表 ↗。
为什么书名定为《某魔法的禁书目录》？ ▾
简中旧译主系列漏了「某」字写作《魔法禁书目录》，而外传却译作《某科学的超电磁炮》等。X 系列统一按日版原名（とある…）规范，与外传保持一致格式。
译名和台版、网译一致吗？ ▾
部分不同。X 系列全库统一术语，多跟进魔禁维基最新标准，具体取舍与差异可查阅 译名裁定总表 §八 ↗ 及 作者博客 ↗。
会用 AI 校对吗？ ▾
会。校对流程中引入 AI 辅助查验，主要用于降低长篇文本逐字通校时的人工疏漏；所有改动与疑点仍以日文原版与项目译名裁定为核定依据。
为什么正文改用直角引号「」？ ▾
弯引号“”属中西文共用码位（U+201C/201D），混排或字体回退时易按西文字体渲染为窄比例导致间距局促；直角引号「」属中日文专属全角码位，更契合方块字且贴合日版原著的阅读习惯。
为什么要压缩图片？ ▾
未压缩单卷常超过 15–20 MB，极易导致移动端翻页与加载卡顿。经无损级算法压缩后体积大幅精简，且在各类屏幕上画质几乎无损。
对阅读器有什么要求？ ▾
X 系列深度运用了 Ruby 注音、注脚跳转与分页控制等 EPUB 进阶排版特性。请勿使用多看阅读或手机自带阅读器，建议参考 阅读器测评 ↗ 挑选。
遇到错别字或漏段，能在 GitHub 提 Issue 或 PR 吗？ ▾
请勿在 GitHub 提交 Issue 或 PR。本项目在 GitHub 上主要用于版本归档与自动打包；勘误反馈与译文探讨请直接加入 X 系列专属交流群（953679671）。
和魔禁维基、汉化组是什么关系？ ▾
无直接关系。本项目为同好独立发起与维护，非魔禁维基或汉化组官方出品。
