## 简介

《魔禁》电子版主要分台译与网译两类：台版严谨但用词偏离大陆习惯；网译贴合大陆语感但错漏较多。X 系列兼取两者之长：旧约与新约以台版为底本，创约及番外以网译为底本，全系列对照日文原版逐行核校；官方后续出新卷时再行复校整合。

## 各版本对比（电子版）

| 维度 | 网译 | 台版 | X 系列 |
| :--- | :--- | :--- | :--- |
| **底本校对** | 译本参差，疏漏与误译较多 | 质量较严谨，但部分卷未出版 | 综合两者底本，对照日文原版通卷逐行精校 |
| **译名术语** | 符合大陆习惯，但部分早期译名过时 | 台湾习惯用语，与主流社群存在差异 | 大陆自然语感，全库统一且跟进维基最新标准 |
| **原文注音** | 大多缺失注音与背景注释 | 仅保留日文注音，无中文译注 | 完整还原日版假名注音（Ruby），增补背景译注 |
| **插图修嵌** | 分辨率参差不齐，部分未汉化 | 早期扫图偏模糊，繁体嵌字 | 原图无损级重压，全彩图/插图简体中文精修嵌字 |
| **排版适配** | 格式混乱，缺乏统一排版规范 | 仅基础版式，多端兼容度有限 | 严格 CSS 排版规范，彻底杜绝移动端分页漂移 |
| **后续维护** | 基本已停止维护 | 商业出版后不再订正 | 长效维护，根据社群反馈与官方新卷持续勘误 |

## 反馈

勘误与优化离不开大家的参与，阅读中遇到问题欢迎在群内指出：

- **文字与排版报错**：错别字、漏标点、漏段、格式错乱等明显问题，附带截图或卷页即可直接反馈。
- **译文探讨**：对译文理解有异议时，欢迎结合日文原文或英翻共同商榷。
- 反馈前请尽量确认手头书籍已更新至最新版。

## 常见问题与说明

> 本节部分说明由 Chansey 整理。

- **会用 AI 校对吗？** 会。校对流程中引入 AI 辅助查验，主要用于降低长篇文本逐字通校时的人工疏漏。
- **为什么要压缩图片？** 未压缩单卷常超过 15–20 MB，极易导致移动端翻页与加载卡顿。经无损级算法压缩后体积大幅精简，且在各类屏幕上画质几乎无损。
- **为什么书名定为《某魔法的禁书目录》？** 简中旧译主系列为《魔法禁书目录》，外传却译作《某科学的超电磁炮》等。X 系列统一按日版原名规范，与外传保持一致格式。
- **为什么正文改用直角引号「」？** 弯引号在西文混排时易退化为半角导致间距坍塌；直角引号形态更契合方块字，且贴合日版原著阅读习惯。
- **对阅读器有什么要求？** X 系列深度运用了 ePub 进阶排版特性，部分阅读器可能出现错位或字体缺失，建议参考 [阅读器测评](https://docs.qq.com/sheet/DUWtiZ3dBbXZFWGR5?tab=000001) 自行挑选。
- **译名和台版、网译一致吗？** 部分不同。X 系列全库统一术语，多跟进魔禁维基最新标准，具体取舍与差异可查阅 [译名裁定总表](docs/translation-name-rulings.md) §7.1 及[作者博客](https://toaru.huijiwiki.com/wiki/Project:%E6%B2%99%E7%9B%92/%E7%9F%A5%E4%B8%80%E4%B8%80)。
- **和魔禁维基、汉化组是什么关系？** 无直接关系。本项目为同好独立发起与维护，非魔禁维基或汉化组官方出品。

## 通过智能体使用仓库

除阅读 EPUB 成品外，可向智能体提出中文检索、成品检查、本地打包或原文核对请求。中文功能无需额外挂载资料；原文查询由智能体先定位已有来源，必要时从完整 BW 提取包生成工作源，并说明实际核验范围与仍缺的材料。

智能体的处理流程和按角色准备资料的清单见 [资料访问与受阻说明](docs/agents/reference-access.md)，工具参数与执行边界见 [工具合同](tools/README.md#克隆后的运行环境)。
