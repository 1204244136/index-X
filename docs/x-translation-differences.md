# X 版译名与灰机 Wiki 译名表的固有差异

文档职责与入口见 [文档索引](README.md)。

本文档记录本项目（X 版）与灰机 Wiki（huijiwiki）译名表之间**人为制定的固有差异**与取舍考量。原载于灰机 Wiki 博客/沙盒页面（`Project:沙盒/知一一`）。

## 性质与用法

- **取舍而非缺陷**：这些差异两侧各自维持自身写法，**不计入待改、不得按表回改**（见[译名裁定总表](translation-name-rulings.md)）。
- 日文锚点与注音写法以 [翻译规范](translation-spec.md) 六.5 为准；本表不另维护规则。
- **门禁顺序（不可颠倒）**：工具先做**折叠归一化**（见翻译规范六.5），再用**折叠后的锚点**匹配本清单，命中后才按 X 版写法判定。即「码位折叠 → 本清单 → 落地判定」。若拿未折叠的锚点直接查本清单，源侧的妥协码位就对不上。
- **同时是机器可读的门禁**：`tools/check_translation_table.py`（译名表 ↔ 成品落地核对）加载本表——命中本表的锚点按 **X 版写法** 判定，成品用 X 版写法即算落地，不会因为没采用表侧写法而被报成「未落地」。
- **注音一律用 `<ruby>` 写在写法列里**（如 `<ruby>主神之枪<rt>冈格尼尔</rt></ruby>`），不写进「说明」列。脚本按项目惯例**只取基文**（先删 `<rt>/<rp>` 再剥标签）参与比对，注音本身不参与匹配。
- **列义**：`日文锚点` 用于匹配译名表的 `Base_Ori`；`表侧写法` 取自译名表的 `Base_Trans`／`Ruby_Trans`（表内以 `【】` 包装的标注格式在本文档中省略）；`X 版写法` 是本项目成品的写法，同一锚点有多个可接受写法时用 `／` 分隔；`—` 表示该侧未登记或两侧一致。
- **格式约定**：本表的「差异清单」是一张 Markdown 表格，改表时保持列数与列序不变。

## 类别规则

- **符合语境**：台版按上下文选词，X 版统一为单一写法。
- **中文注音**：基文与表侧一致，只把 `<rt>` 注音由原文片假名改为汉译。
- **混乱统一**：同一注音（片假名）在表侧有多个汉字写法时，X 版统一为一个写法，并把注音改用拉丁字母。
- **杂项／原创词**：日文 neta 或外来语在 X 版另拟中文名（不音译、不照搬表侧）。
- **炼金术器具专名**：原文一律作「汉字类别名＋片假名专名」，X 版统一为**类别名汉译＋专名音译**。
- **泰勒玛与克劳利**：格言保留出版源的文白格言体与读音注记；`ハザード` 取「灾祸」义项，并兼顾事件与具体的物两种指代。
