# EPUB 结构规范（行模板、标题、译注页与分页衔接）

文档职责与入口见 [文档索引](README.md)。

本文件是 `EPUB/` 中日 XHTML **结构与行对齐**的规范正文：固定行模板、行对齐原子、标题分层、译注页结构、换页衔接、图片行与包装页边界。命名与表头形态见 [EPUB 命名规范](epub-naming-spec.md)；译文语言规范见 [翻译规范](translation-spec.md)；机器判定的入口与参数见 [工具合同](../tools/README.md)。行数必须对齐这一硬要求与检查命令见 [AGENTS.md](../AGENTS.md)「Agent 操作边界」。

## 一、固定行模板

中日两侧带正文的 XHTML 使用统一固定行模板（绝对行号，不随内容有无偏移）：

1. `<?xml …?>`
2. `<!DOCTYPE html>`
3. `<html …><head>…</head><body…>`（可并入篇首图片，图片位于 body 开头）
4. `<h1>…</h1>` 独占一行；无 h1 则空行占位
5. `<h2>…</h2>` 独占一行；无 h2 则空行占位（中文列表型包装页可为 `<ul>`/`<ol>`）
6. 正文首行 `<p>…</p>`，永远在第 6 行

**L5 槽位规则**：

- 标准正文页：`<h2>` 独占行（开标签+内容+闭标签同行）或空行占位。
- 中文列表型包装页（Note、Introduction 等）：若该文件没有 h2，允许 `<ul>`/`<ol>` 列表包装开标签独占 L5，语义上等价于"结构占位"（不是标题行），第一条列表项 `<li>` 从第 6 行开始。
- 日文包装页不适用列表占位规则（保持原样快照）。

「空行」指无任何内容的空白物理行，不得用 `<br/>` 或空格占位。纯图片页和无正文页不适用此模板。

**L6 包装页边界**：标准正文首行必须为完整 `<p>`，中文列表型包装页为首条 `<li>`。中文作品级包装页原有多段语义 `div` 可保留其开标记与完整首段 `<p>` 同在 L6；该例外不允许标准正文用裸 `div` 或裸文字作首行，也不允许多个同级正文块挤在一行。

## 二、行对齐原子

- h1、h2 的外层标题块必须独占一个物理行：开标签、标题内容和闭标签同行，该行不得再有与标题同级的图片、文字或其他块。标题内部允许 `ruby`、`span`、`sup`、`em`、`b` 等行内语义标签，但不得使用 `<br/>`、`div`、`p` 等排版或块级标签。同一配对文件两侧的 h1/h2/空行位置一一对应，总行数一致；缺元素的一侧用空行补齐。行数对齐时不得向任一侧添加原始作品中不存在的结构标签（如 `<div>`、`<br/>` 等）或换行符来凑行数；「原始」指中日任一侧的制作源（日文 BW 分页源、中文出版源）：结构元素（标题、插图行、场景分隔 `<br/>` 等）只要在制作源中真实存在、仅被某侧制作管线丢失，允许在对应位置补回，属恢复源结构而非对齐填充；若一侧有多余的结构标签行或换行，应折叠或删除该侧来减小行数差。日文 h2 前后多余的 `<br/>` 只删除等于行数差的数量。
- 正文区以顶层块为行对齐原子：每条物理行只能承载一个同级正文块。禁止用 `<p>…</p><p>…</p>`、`<p>…</p><hr/>` 等方式把多个块挤入一行，也禁止把正文与 `</body>`/`</html>` 闭标签拼在同一行。若一侧一个段落对应另一侧多个段落，必须先确认语义关系，再通过删除内部段落边界真正合并为一个 `<p>`；不得只删除物理换行。无法安全合并时保留问题并交由人工决策。

## 三、标题结构

- 单层标题规范为 `<h1>第一章</h1>`；标题末尾仅用于留白的 `<br/>` 是排版噪声，直接删除，不得转成空 span、空行或正文间隔。
- `<br/>` 如果分隔主标题、副标题、英文题名或特殊编码，代表视觉分层，禁止直接删除后把文本粘连，也不得用空格、斜杠等字符冒充分层。应把各层重建为有语义的行内 span，整个 h1 仍保持在 L4 的一个物理行。例如：`<h1 class="heading-lines"><span class="heading-main">第一章</span><span class="heading-subtitle font08">魔法师她降临在高塔</span><span class="heading-code font06">FAIR,_Occasionally_GIRL.</span></h1>`。
- 只有实际存在的标题层才生成 span；二层标题省略 `heading-code`，单层标题不套空包装。`ruby`、`sup` 等原有语义标签保留在所属 span 内。原 h1 中仅用于居中或分组的 `div` 必须移除；如外层标题本身没有等价样式，应通过样式类补回，不得保留内联 `style` 或块级容器。
- 视觉换行由书内已引用的 CSS 实现，不再由 XHTML 的 `<br/>` 实现。受影响书籍的样式表应加入：`.heading-lines > .heading-main, .heading-lines > .heading-subtitle, .heading-lines > .heading-code { display: block; }`。`font08`、`font06` 等已有字号类可与语义类并用，但不得把字号类当作标题层语义。
- 迁移必须保持每一层的可见文本、顺序、标点、ruby/sup 内容和原有字号语义；只能清理 `<br/>` 周围由排版产生的空白。迁移前后的标题纯文本按层比较必须一致，不能只比较把所有层拼接后的总字符串。
- 中日配对只要求 h1/h2 外层标题所在物理行对应；两侧实际存在的标题层数可以不同，不得为凑层数添加空 span。NCX/nav 中已有标题保持不变；若工具从标题重新生成纯文本标签，应按 `heading-main`、`heading-subtitle`、`heading-code` 顺序以单个空格连接非空层，禁止无分隔粘连。
- 标题可见文字与语言的维护以 [翻译规范](translation-spec.md) 五.6 为准；结构迁移不得借机改写标题。
- 历史批量迁移使用 `python tools/migrate_heading_breaks.py` 预览，确认后加 `--apply` 写入。工具只接受已审计的二层/三层 span、直接副标题、`sup` 编码层和单层尾随换行结构；任一未知结构都会在写入前停止，禁止扩大为宽松猜测。
- `check_alignment.py --strict` 全局阻断 h1/h2 内嵌 `<br/>`、`div`/`p` 块级包装以及跨物理行标题。新增、重建或再次同步的 XHTML 不得重新引入；发现旧源回流时应重新运行专用迁移工具，不得临时放宽门禁。
- 迁移遵循 EPUB 写入边界：内容写入只改 `EPUB/` 中的 XHTML 和对应书籍 CSS，写入前后运行 `publish_auto.py` 同步；不得把 `.cache/epub-work` 当作写入目标。

## 四、译注页（Note）结构规约

译注页是中文独有的作品级包装页，`S<作品号>-Note.xhtml` 当前 73 个 / 856 条。**注释正文的写法见 [翻译规范](translation-spec.md) 三.2**，本节只写文件结构。

结构层已事实收敛（属性完整性 855/856、编号连续性 73/73 全部通过），因此本节**只列有实测偏离的项**，其余交给 `tools/` 实现，不复制常量与正则。

- **外壳**：XML 声明用单引号 `<?xml version='1.0' encoding='utf-8'?>`；`<head>`、`<link>`、`<title>` 三者之间不留空格；`<title></title>` 为空。全库 73:1，唯一偏离在 `S3_11`。
- **`<h1>` 固定为 `<h1 class="center">译注</h1>`**，独占 L4。73/73 逐字一致，但该值原先只硬编码在两个生成器里、无任何成文；现提取为 `tools/xhtml_slots.py` 的 `NOTE_H1` 常量，本节与生成器共用它，不另存副本。
- **容器必须是 `<ul>`，不得用 `<ol>`**（`<ul>` 72 : `<ol>` 1）。`tools/reorder_notes.py` 依赖 `<ul>` 定位条目范围，遇 `<ol>` 会抛未捕获异常，而 `normalize-epub-text.yml` 每日会跑到该路径。
- **条目标签固定为 `<li epub:type="footnote" id="noteN">`**：`epub:type` 在前、`id` 在后，两个属性都不得省略；`<li>` 一律顶格，不缩进。全库属性顺序 713 : 142 且 6 个文件内部混排。
- **行内标签只允许 `ruby`、`i`、`span`（含 `lang`）**；禁止 `table`、`dl`、`br`、`p`、`div`（这五类全库为 0，规则用于防回流）。
- **编号**：`id` 为 `noteN`，从 1 连续、不留空号，且顺序与正文 `noteref` 首次引用顺序一致。判定实现唯一来源是 `tools/notes_core.py` 与 `tools/check_note_order.py`，本节不复制正则。
- **说明型条目**：`S0_00-Note.xhtml` 第 7 行「阅读器不支持弹注」提示是**唯一合法**的无 `id`、无 `epub:type` 条目，不参与 `noteN` 编号序列与 `reorder_notes.py` 重排。该登记不构成对其他文件放宽属性要求或编号连续性的依据。
- **列表包装页集合**：`check_alignment` 与模板重建必须共用同一集合（`information`／`introduction`／`note`／`special` 四类）。不得为纯图片页（`cover`／`back_cover`／`illustrations`）开放 L5 列表槽位。
- **工具契约**：`reorder_notes.py` 遇非 `<ul>` 必须**显式拒绝并报告**，不得抛异常、也不得静默改写容器标签；`check_epub_health.py` 覆盖本节的外壳、容器、属性顺序、缩进与行内标签五项。

## 五、换页衔接与场景分隔

- 换页衔接处理：分页源（BookWalker 等）合并为章节文件时，按衔接处两侧的页型定间距——文本+图片+文本（跨整页插图）时，图片包裹的 `<p>` 标签中加入 `class="pb"`（如 `<p class="fit pb"><img …/></p>`），图片与前后文本无缝衔接且前后文本段落不额外加换页标记；文本+文本（连续两页正文）衔接处在前一文件末尾段落追加 `class="pb"`（如 `<p class="pb">文本A</p>`），不插入额外空白行；若前一页末段与后一页首段是同一段落的断续，先按语义拼回完整段落，不再套用换页标记。页首/页尾的填充 `<br/>` 属排版噪声，合并时删除。整页无文本且无图/SVG 的空占位页用 `tools/fix_empty_placeholders.py` 删除并前移后续序号。全页插图页（SVG、`body.p-image`）保留为图片行，随归属章节合并；中日两侧同一位置的换页标记与视觉间隔数量一致。
- 场景分隔空行按制作源保留：原文空一行译一行、空两行译两行、超过两行统一保留三行可见间隔；分页边界使用 `pb` 而非独占 `<br/>`。这属于源结构处理，不能用来填充译文或凑配对总行数。
- 中文侧表达同一分页边界的 1~2 个独占 `<br/>` 是**旧合页写法**，已被日文侧 `class="pb"`（不占行）取代，属多余物理行，用 `tools/fix_legacy_pagebreak_br.py` 删除。判定必须逐边界比较两侧的 `<br/>` 连段数量：数量一致的是真场景分隔，不得删；只有中文侧多出的部分才是遗留。日文侧本来就更长、或遗留数超过该文件总行数差时，工具必须拒绝删除并交人工，不得为凑行数删掉真分隔符。

## 六、图片行、篇首插图与纯图册

- 篇首插图并入第 3 行头部行（body 开头，图片在标题前）；正文中的图片正常占正文行，两侧图片行必须一一对应（`gaiji`/`height-2em` 内嵌字形不计；已确认的文本化图片例外不在此枚举，唯一事实来源是 `alignment_rules.py` 的 `TEXTUAL_IMAGE_HEADERS`，配对检查整体豁免）。
- 画集／纯图册源不进入文本预处理与归档：整本只有整页图片、没有文本页时，`bw_preprocess.py` 整本跳过；仅显式 `--force-image-only` 可强制处理。画集源留在外部 BW 提取目录，不能以相同日期猜测中日配对。`S6_24.12.10` 的画集本身不归档；其中 SS 已独立转录为单文件日文 EPUB，现按该 SS 与中文作品常规配对并检查模板。当前配对与模板例外唯一事实来源为 `alignment_rules.py`，新增例外须写明依据。

## 七、日文侧规范化与缺失结构补齐

- 日文侧规范化：头部标签跨行折叠为一行；填充 `<br/>` 删除；跨行 h1/h2 折叠为单行；`<div class="start-3em/start-5em">` 容器内嵌标题按语义重建为独立 `<h1>`；p 型标题（`font-1em10/30`、裸 `<p>あとがき`、`<p>译注` 等）转为 `<h1>`；数字小节 `<p>N</p>` 转为 `<h2>`。中文侧裸 `<div>` 仅作为单块排版包装时清除标签，保留带 class 的语义容器；相邻裸开闭标签形成 `<div></div>` 时删除该空行。中文 Note 等列表型包装页中 `<p>` 包裹 `<li>` 时剥离 `<p>`，保留 `<li>`。
- SP 等稳定名称篇目（S1_25-*）日文侧补 `<h1>`（标题取自日文原版目录）；日文缺失的 h2 小节补在对应空行位置。
- S6 单文件作品：中文 Main/Chapter 含「正文」类 h1 时应删除；无标题文件 L4/L5 为空行、正文固定第 6 行；正文尾部的附赠文本归入 Information 页；中文侧插图应补入日文侧（复制图片、OPF 声明、占位行替换为图片行）。

## 八、包装页、附录与分页源映射

- 中文包装页（Information/Note/Introduction 等作品级文件）头部行内的 h1 提取到第 4 行，按同一模板处理。日文独有包装页（p-fmatter 等原样快照）不参与中日对齐检查。
- 分页源的稳定表头不能仅按 `h1` 或页码机械推导。无标题的新语义单元（尤其后记作者署名之后的「尾声」）、正文插图与作品级图片包装页必须先按内容确认；工具应使用逐页显式映射保存确认结果，实际分页与映射不一致时阻断，不得让插图或包装页无条件沿用上一正文表头。
- 判定著者介绍/版权包装页只允许用「短页 + 标记位于页首两段之内」的条件：长正文页（如尾声）中叙述性出现「プロフィール」「著者紹介」等词不得被整页判为包装页而丢弃，必须先按正文段数与标记位置确认。
- 「尾声」的收束边界（后记之后遇到非正文页即进入书末附录、其后页不并入后记）见 [EPUB 命名规范](epub-naming-spec.md) 二。
