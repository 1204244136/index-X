# 译名选取规范

本文件是本项目**译名选取的规范正文**，与 [翻译规范（EPUB 成品层）](translation-spec.md) 并列：`translation-spec.md` 写标点、注音、译注、语义与证据边界，本文件写某一译名在多个候选之间如何取舍；判定译名选取优先级时以本文件为准。

以下为本项目对译名选取的翻译策略（原载于灰机 Wiki 博客/沙盒页面 `Project:沙盒/知一一`），优先级由高到低大致遵循以下原则。

## 一、从俗

当某一译名不存在严重问题且较其他版本有压倒性优势时：

- **亚雷斯塔·克劳利**（虽然 Aleister Crowley 在现实中更常用的中文译名是阿莱斯特·克劳利，但亚雷斯塔已经深入某系列官译俗译至无可更改的地步）
- **迪翁·福春**（该译名不仅在使用频率上显著大于其他版本，且现实中有关 Dion Fortune 的中文资料如维基百科也开始使用这个译名）
- **格雷姆林**（使用频率上显著大于「捣蛋鬼」，且适当情况下采用音译比起意译更能体现出是专有名词）

## 二、从官

当以台湾角川为主的官译不存在地域词汇差异或严重问题时，从俗的译名和官译差异不大时也可能考虑将其微调至官译（通常不考虑采用动画官译，因为动画的官译来源过于繁杂）：

- **欧提努斯**、**克兰斯·R·札尔斯基**
- **御坂网路**、**桃莉**、**劳拉·史都华**（反例）（「网路」「桃莉」「史都华」都是存在明显地域词差译的译名，如果日后增加简繁转换功能可能会考虑加入转换词典）
- 「创约五中爱丽丝的相关译名」（采用《爱丽丝梦游仙境》中的通行译名）

## 三、自拟

不存在译名或所有译名都有明显问题时，或对从俗的译名进行微调时：

- **卡提纳正统**（格式整齐的カーテナ＝オリジナル（Curtana Original）与カーテナ＝セカンド（Curtana Second）分别叫「正统卡提纳」与「卡提纳二世」未免太奇怪了些）
- **阿拉迪娅**（微调后采用了更为标准的音译转写）

## 四、外国人名/专名的原语还原原则（防日语中转）

对于非日语背景的外国人人名、外国地名、神话名与专有名词（如欧美、俄罗斯、斯拉夫、近东、希腊、拉丁等语种角色与设定），日文片假名仅是原作者依据日语发音系统转写的外来语记音。自拟或审定此类译名时，**严禁直接依据日语片假名读音逐字音译（即禁止经由日语中转二次音译）**。

执行流程与准则如下：

1. **反推原语**：必须先结合角色的国籍、文化背景、出场地及作品设定，反推出其对应国语言的原文字面拼写（拉丁字母、西里尔字母等），必要时参考英文版官方命名或通行转写；
2. **直接汉译**：直接根据该源语言的权威汉译音译规范（如新华社《世界人名翻译大辞典》、《世界地名翻译大辞典》、各语种外语译音表），从原语直接译为中文；
3. **典型纠偏与严式翻译准则**：
   - **优先采用严式翻译**：自拟外文音译优先采用严式音译（严格依据源语言音标/字母与规范译音表一对一严密转写，保留双元音分写与完整音节，杜绝含糊合流或日式模糊音译）；
   - **剔除开音节化产生的多余元音**：如俄语词尾 `-ск`（-sk）经日语 `-スク` 容易被机械译出多余音节，应按俄语译音表还原；
   - **纠正常见用字中转失真**：如俄语 `-ша`（-sha）受日文片假名 `シャ` 影响极易被习惯性套用为日式汉化常见的「夏」，按俄汉译音表应严格还原为「沙」（如 Браша → 布拉沙）；
   - **剔除日语记音过程中的失真与无据增减**：纠正清浊音混淆，剔除转写过程中凭空增添或脱落的鼻音（如原文并无「ン」却译出鼻音「兰」「因」等）。

4. **典型范例（旧约 20 俄罗斯成教魔法师）**：
   - **原文**：`ブラッシャ＝Ｐ＝マールハイスク`
   - **原语还原（俄语）**：`Браша П. Мархайск`（拉丁转写：*Brasha P. Markhaysk*）
   - **严式翻译推导**：
     - 名 `Браша`：`Б`=布，`ра`=拉，`ша`=沙（俄语 `-ша` 严式规定为「沙」，消除日式假名汉化「夏」及臆造鼻音「兰」）→ **布拉沙**；
     - 缩写 `П.`：父称首字母，写作 **`P.`**（保留大写字母，后跟半角句点 `.`）；**中文与外文缩写之间用间隔号 `·`，缩写字母之后用下脚点 `.`，其后不再加间隔号**（依据见 [翻译规范](translation-spec.md) 一.3）；
     - 姓 `Мархайск`：`Мар`=马尔，`хай`=哈伊（严式逐音节拼写，严格保留双元音分写，非合流俗译「海」），`ск`=斯克 → **马尔哈伊斯克**；
   - **最终定名**：全名 **`布拉沙·P.马尔哈伊斯克`**（简称 **`布拉沙`**）。

## 五、补充

- 也有不符以上优先级的特殊例子，如为了保持系列作品译名一致而将《魔法禁书目录》改为《某魔法的禁书目录》等；
- 有时属于以上三种情况中的哪种会有争议，建议另行讨论；
- 自拟人名地名音译建议按照 [wikipedia:zh:Wikipedia:外語譯音表](https://en.wikipedia.org/wiki/zh:Wikipedia:%E5%A4%96%E8%AA%9E%E8%AD%AF%E9%9F%B3%E8%A1%A8)，先查询权威译名词典、新华社历史资料库的收录内容，若未收录再根据源语言参照《世界人名大词辞典》与《世界译名大辞典》的译音表推出来。
