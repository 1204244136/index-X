# 插图文字 → 正文映射

> 回指 [文档索引](README.md)。

## 一、这份表是什么

把各卷**彩色插图**（彩色口絵、彩色目录图）上印的文字，逐条对到该卷**日文正文**的
`XHTML 文件 + 物理行号`。用途有两个：查某张彩页上的字在正文哪一行；插图页与正文对不上时，
先确认这句到底是原句、节选还是改写。

覆盖 S1（旧约）、S2（新约）、S3（创约）、S4（暗部）、S5（外典）、S6（日期短篇）共 88 卷、
327 张彩色插图，565 条记录。

## 二、口径

- **只统计彩色插图**：`kuchie-*`（彩色口絵）、`toc-*`（S1 的彩色目录图）、S1_25 的 `sp`。
- **黑白插图整体不纳入**：S1–S3 的 `p###`／`t###`／`img-###`、S4 的 `i-###`、S5 的 `m-###`（单色口絵）、
  S6 短篇的 `p#`。既不记录，也不进覆盖表。
- **不记录**：人物标签（角色名＋称号）、书名／作者／插画师署名、目录章节标题、拟声词。
- **整张剔除**：背景介绍页（世界观／组织／历史／装备／地点解说，如 S2_18 的『窓のないビル』
  『ブライスロードの戦い』、S2_19 的『プロセッサスーツ』）与彩页宣传语（如 S4_01 的
  「これは、学園都市の『暗部』に生きる少女たちの物語──。」）——正文里不会有对应句，一行都不记。
- **记录**：彩色插图上的对白（`「」`内文字）、故事内绘卷式叙述（如 S1_19 口絵的『序章』童话）。
- 图片文字与正文有差异时**照实记录**，用备注区分节选、节选改写、改写、表述略有差异、标点不同，
  不判定「正文或图片有错」。
- **同句在正文出现多处时，表里只写第一处**，其余位置写进备注，形如
  `同句3处，另见：S1_01-02.xhtml:56、S1_01-02.xhtml:58。`。

## 三、列

| 列 | 含义 |
| --- | --- |
| 卷号 | `S1_03`、`S5_01_03`、`S6_14.09.10` |
| 图片 | 彩色插图文件名（日文侧 `item/image` 下的原名） |
| 图片文字 | 按图片**实际印字**转录，不按正文回填 |
| 正文文件 | 该卷日文正文 XHTML 文件名 |
| 行号 | 该文件的**物理行号**（从 1 起）；跨多段时为 `起–止` |
| 正文原句 | 该行去掉 ruby 后的正文原文（用于校验与重新定位） |
| 备注 | 节选／改写／标点不同／同句多处／正文无此句等 |

`正文文件` 为空表示该句在正文里没有逐字对应（备注写明是「正文无此句」还是「场景对应」）。

## 六、维护

1. **行号会随日文缓存重建而漂移**。每次 `./tools/pull.ps1` 之后跑一次
   `python tools/check_illustration_mapping.py`：它逐行回查锚点，行号不符时按 `正文原句`
   重新定位并给出建议行号，未解析项非零退出。
2. 新增系列或新卷时：清单 → OCR → 逐卷看图复核 → 重新生成本表。复核口径见本文件二、三节。
3. 本表是**人工视觉复核的产物**，不是脚本可再生的派生数据：`图片文字` 的转录与
   `备注` 的判定都来自逐张看图，重跑脚本只能重建候选，不能重建结论。

## 七、已知限制

- 纯标点文字（如「…………！！」）规范化后为空，无法在正文里检索。
- 同一句在正文多处出现时无法判定插图取自哪一处，按「第一处 + 备注另见」处理。
- 转录以看图为准，个别字形（如 `っ`／`ー`、`＝`／`=`）可能与原图有细微出入。
- 不在 `「」` 内、以手写大字排的绝叫与拟声（如 S4_05 麦野格的「ギャアアア」）按拟声不记录。
