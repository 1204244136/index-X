# 「ヘルメス学」中文译名统一为「赫耳墨斯学派」（2026-09-20）

## 背景与裁定

创约 1 校对复核过程中发现同一日文锚点存在两套中文写法：

- **术语表**（QMind 知识库 Notebook「项目规范」/ `Data_Translation.tabx.xlsx`，条目出处标「正传旧约 02」）：`ヘルメス学 → 赫耳墨斯学派`，类别「宗教神话」，注「一种哲学思想，和炼金术相关」。
- **已出版成品**：`ヘルメス学` 在全库 9 个正文行中一律作「赫耳墨斯主义」。

即术语表条目与成品正文长期不一致。本轮裁定：**以术语表为准，统一为「赫耳墨斯学派」**，并把成品侧既有异译一并回收。

## 检索与判定口径

- 锚点必须是日文写法，不是中文词形：逐行取中文含「赫耳墨斯」的行，按内容序与固定行模板对齐到日文同行（先剥 `<rt>` 再取纯文本），确认该行日文含 `ヘルメス学`。
- 同行若另含 `ヘルメス主義` 则阻断交人工（本次 0 处命中）。
- 只替换 `赫耳墨斯主义` → `赫耳墨斯学派`，只改行内文字，不动标签、不增删物理行、不改换行风格。
- 执行器：一次性脚本（显式映射 + 逐条预检，预检不过即整本不写盘），按 AGENTS.md「工具与记录的边界」跑完即删，不入 `tools/`。
