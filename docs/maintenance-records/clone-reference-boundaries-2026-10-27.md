## 修改结果

| 范围 | 已落地行为 |
| --- | --- |
| 中文独立检查 | 翻译规范、译注顺序默认检查归档，保留显式旧参数；空输入或无匹配作品报前置错误，无译注页明确不适用；成品体检补空选书与报告写失败处理 |
| 检索与定位 | 中文按作品优先缓存、未缓存作品回退归档；显式根不回退；双侧查询可保留中文结果并说明无日文，日文单侧查询及原文定位缺输入明确失败 |
| 术语与发布预检 | 术语核验分别记录命中、未覆盖与已登记例外，strict 不接受未完成范围；显式日文发布预检要求参考完整，内部同步保留单侧能力并报告真实覆盖；混合选书中的不存在项会阻断，内部删除流程保留 |
| 译名表 | 显式选书逐本核定双侧覆盖，默认交集列明单侧作品；只采集实际正文，元数据、样式、脚本、注释和标题不混入正文；中文宿主作为辅助来源单列 |
| 差异、语义与呼应 | 支持归档与独立日文根；零可检查配对报前置错误，空白文件与被其它有效配对掩盖的空书不能算通过，部分覆盖持久化；strict 对应完整范围；有可靠配对但零候选或零模式命中仍属正常结果；语义检查先验证输入再准备模型 |
| 图片对照 | 支持独立根并保留旧双侧缓存入口；零配对或任一侧无图片不算完成；部分缺对应作品保留范围说明，图片比对算法保持原口径 |
| 配对修复 | 先核对整个选定范围，再写入；缺参考作品／正文、空书及空白配对文件不能静默跳过，已登记例外只豁免自身；普通中文正文对应无正文日文时拒绝配对规范化 |
| 图片结构清理 | 删除普通正文图片容器结构行前核对实际日文文件与改写后的行数、行类型；缺源时整批拒绝，写失败回滚；仅包装裸图仍可单侧执行 |
| 改动分级与环境说明 | 分级汇总始终显示日文覆盖及未核验状态；工具合同说明输入准备、单侧能力与各工具实际覆盖 |
