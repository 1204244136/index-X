# 荧幕术语「大画面」中文异译统一（2026-02-14）

## 背景

日文原文把飞船腹部、百货公司外墙上那块广告屏写作 `<ruby>大画面<rt>エキシビジヨン</rt></ruby>`。中文版在**有注音**处已逐点统一为 `<ruby>大屏幕<rt>Exhibition</rt></ruby>`，但日文未注音的叙述句里出现了照搬日文汉字的「大画面」，以及「巨大荧幕 / 大银幕 / 巨大屏幕 / 巨型屏幕 / 巨大画面 / 大型显示屏 / 液晶屏幕 / 显示器」等异译。

统一工具：`tools/fix_screen_term_variants.py`（把日文「大画面」锚点范围内的异译统一为「大屏幕」）。

## 结果

- 日文「大画面」锚点 **62 处**，其中 **60 处**有中文配对
- 统一 **18 处**写法；统一后 60 处中文全部为「大屏幕」

## 范围与口径

- **只处理显式映射**：逐条记录（中文文件基名、行号、原串、新串），要求文件在 `Text/` 下唯一、行号有效、原串在该行**恰好出现一次**；任一条不满足即整次预检不写盘。不做全局模糊替换。
- **范围限定**：普通叙述里的「屏幕 / 画面」（电视画面、显示器、手机屏、网吧投影等非该物件）不在范围内。日文侧与原作排版（含 `<ruby>` 注音）一律不改。
- **不破坏对齐**：只改行内文字，不增删行，因此中日行数对齐与 L1–L6 模板不受影响。
- **幂等**：重复运行识别已统一行并报告「跳过」，不重复改写。
