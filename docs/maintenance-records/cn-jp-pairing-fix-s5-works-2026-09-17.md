# 中日配对口径修正与 8 部 S5 作品纳入对齐检查（2026-09-17）

## 结论

`check_alignment.py` 长期存在两层互相掩盖的缺陷，导致 **8 部 S5 作品从未参与任何配对检查**，
另有 2 部无日文对应的中文书从未参与单侧模板检查。两者都不报错，只表现为「检查通过」。

| # | 缺陷 | 后果 |
| --- | --- | --- |
| 1 | `epub_ids.japanese_book_id()` 把 `S5_AA_BB` 折叠成 `S5_AA`（合订卷号） | 8 部 S5 作品的日文目录查不到，被当成「无日文对应」静默跳过 |
| 2 | `check_alignment.py` 的「未配对 CN」循环嵌在 `for … in pairs:` **内部** | 没进 pairs 的书连单侧模板检查也拿不到 |
| 3 | 缺陷 2 掩盖了缺陷 1：S5 既没配对、也没单侧检查，两层都不报错 | 只有把配对修好才看得到单侧检查的缺口 |
| 4 | 配对循环里 `if not has_body(jl) or not has_body(cl): continue` | 「一侧纯图片页 ↔ 一侧正文页」的配对既不检查也不报差异，S5 全部 7 部作品的扉页在报告里消失 |

修正后：中日配对作品 **67 → 74**，检查文件 **913 → 1105**。

## 缺陷 1：日文侧不是合订卷目录

`japanese_book_id()` 的注释写的是「中文独立作品 → 日文合订卷」。这个中间形态**不是归档的形态**：
`tools/split_s5_epubs.py` 把每本「外典书库」合订卷拆成独立作品，并用**两段作品号**命名输出
（`SPLIT_SPECS` → `[S5_01_01]とある魔術の禁書目録SS 神裂火織編`、`[S5_01_02]…`、`[S5_01_03]…`）。

对照两边实际目录，S5 两侧 works id 完全同名：

| 作品号 | 中文目录 | 日文目录 |
| --- | --- | --- |
| `S5_01_01` | `[S5_01_01]某魔法的禁书目录SS 神裂火织篇X` | `[S5_01_01]とある魔術の禁書目録SS 神裂火織編` |
| `S5_01_02` | `[S5_01_02]某魔法的禁书目录SS 必要之恶教会的考验X` | `[S5_01_02]とある魔術の禁書目録SS 『必要悪の教会』特別編入試験編` |
| `S5_01_03` | `[S5_01_03]某魔法的禁书目录 通向恩底弥翁之路X` | `[S5_01_03]とある魔術の禁書目録 ロード・トゥ・エンデュミオン` |
| `S5_02_01` / `_02` / `_03` | 学艺都市篇 / 能力实演旅行篇 / ColdGame | 学芸都市編 / 能力実演旅行編 / コールドゲーム |
| `S5_03_02` | 生物黑客篇 | バイオハッカー編 |
| `S5_04_01` | 斯塔蒂瓦里篇 | ステートバリウス編 |

因此 `japanese_book_id()` 改为**恒等映射**，并在 docstring 里写清「若真出现合订卷目录，按显式别名声明，
不得推导」。这个函数被 6 个工具共用（`check_alignment`、`normalize_paired`、`compare_epub_images`、
`fix_legacy_pagebreak_br`、`restore_cn_scene_breaks`），修在源头即全部受益。

这些工具的失败方式都一样：查不到目录就 `continue` / 记一条 unpaired，**不抛错**。因此
「8 部 S5 从未被规范化/对齐检查过」此前没有任何可见症状。

## 缺陷 2：未配对循环的嵌套

原代码把「未配对 CN 正文/包装」与「未配对 JP 正文」两个循环写在 `for ... in pairs:` 里，
并各自用 `if h in cn_by and h in jp_by: continue` 过滤。于是：

- 缓存里没有日文对应的中文书（`S0_00`、`S6_10.06.26`）永远拿不到单侧模板检查；
- 因缺陷 1 进不了 `pairs` 的 8 部 S5 同时失去配对检查与单侧检查。

修正为：配对循环只做配对检查；**新增独立的「未配对书籍」段**放在配对循环之外，对没有对应作品的
一侧照常做单侧模板检查，并在报告里留一行 `无日文对应作品，仅单侧模板检查` / `无中文对应作品，仅单侧模板检查`。
`NON_PAIR_WORK_IDS` 仍用于「已知非同一作品」的常态跳过（不像未译卷那样值得每天提示）。

## 缺陷 4：一侧纯图片页被静默跳过

配对循环里原本写的是 `if not has_body(jl) or not has_body(cl): continue`
（「纯图片页/无正文页不适用」）。但这里比较的是**两侧**，只要**任一侧**没有正文就整对跳过——
于是「日文整页图片 ↔ 中文正文页」这类配对既不做模板检查、也不报差异。实测有 7 对，全部是 S5 各作品
的首个内容单元 `S5_*_*-01`：

| 作品 | 日文 `-01` | 中文 `-01` |
| --- | --- | --- |
| `S5_01_01` | 整页图片 `<img … -m-001.jpg alt="神裂火織 編"/>`（7 行，无正文） | `-01_Introduction.xhtml` 简介（12 行） |
| `S5_01_02` | 同上（`-m-002.jpg`） | 简介（11 行） |
| `S5_01_03` | 同上（`-m-003.jpg`） | 简介（13 行） |
| `S5_02_01` | 同上（`-m-001.jpg`） | 简介（10 行） |
| `S5_02_02` | 同上（`-m-002.jpg`） | 简介（12 行） |
| `S5_03_02` | 同上（SVG + image） | 简介（21 行） |
| `S5_04_01` | 同上（SVG + image） | 简介（10 行） |

日文侧是「外典书库」合订卷里每部作品的作品扉页（整张宣传图），中文侧没有这个图片页，
改为一张文本化的「简介」页。这与 `TEXTUAL_IMAGE_HEADERS` 已有的 `S2_14-*` 是**同一族**例外
（`S2_14` 是「中文把整页材料图排成文本行」，这里是「中文把整页扉页图换成简介页」），
因此按同一口径登记进 `TEXTUAL_IMAGE_HEADERS`（整表头豁免）。

配套改动：

- `content_index()` 不再按「有无正文」过滤——纯图片页也是合法配对单元，「一侧有正文另一侧无」
  正是要报告的差异；是否跳过留给调用点判定；
- 配对循环改为：两侧都无正文才 `continue`；只有一侧有正文时**默认报告**
  （`一侧有正文另一侧无：日文 N 行（正文 False）/ 中文 M 行（正文 True）`），
  只有登记在 `TEXTUAL_IMAGE_HEADERS` 里的表头才豁免。

验证：临时清空 `check_alignment.TEXTUAL_IMAGE_HEADERS` 后重跑，报告的正是上表这 7 条
（另加 `S2_14` 那 5 条），说明豁免是唯一的抑制来源，且负向自检能证明这一点。

### `S5_01_03-06`：后记被有意并入同一卷的另一部作品

日文末尾有独立的 `<p>あとがき</p>` 与整段后记，中文侧完全没有；中文
`S5_01_03-Information.xhtml` 明写「（后记在 **[S5_01_01]某魔法的禁书目录SS 神裂火织篇X** 中）」。
这是既有的合订卷归并口径，不是缺失内容。

**验证**：把日文截到「あとがき」行之前后，行数 482 vs 483（差的是中文闭合行）、
`h2` 位置、图片行、`<br/>` 位置全部一致：

```
截断后 JP=482 CN=483
br  JP=[66, 69, 199, 202, 222, 224, 239, 241, 300, 303, 348, 350, 448, 450, 462]
br  CN=[66, 69, 199, 202, 222, 224, 239, 241, 300, 303, 348, 350, 448, 450, 462]
h2  JP=[5, 78, 186, 292, 411, 465]   CN=[5, 78, 186, 292, 411, 465]

```

### `S5_01_02-09`：小节标题与图片行互换

```
JP 332 <p><img class="fit" src="../image/S5_01_02-i-753.jpg" alt=""/></p>
JP 333 <h2>６</h2>
CN 332 <h2 id="toc_6">6</h2>
CN 333 <p><img alt="图片" class="fit" src="../Images/S5_01_02-i-753.jpg"/></p>
```

前一行是 `<p class="pb">`（分页边界收束）。中文顺序让 `h2` 开启新页，是合并分页源时应有的形状；
日文侧保持快照原序。两侧 `check_file` 模板检查都是 0 问题，差异纯粹在配对层。

### `S5_02_03`：日文是一页式固定版式，与中文文本化重排非同一形态

```
japanese-text/[S5_02_03]とある科学の超電磁砲 コールドゲーム/
    item/xhtml/S5_02_03-01.xhtml          ← 整个作品一个文件
    item/style/fixed-layout-jp.css        ← 固定版式
chinese-text/[S5_02_03]某科学的超电磁炮 ColdGameX/
    OEBPS/Text/S5_02_03-01_Main.xhtml     ← 5 章文本化重排
```

日文那 22 个 `h2` 是一页式文件里的版式锚点，不是章节标题，逐条比对只会产出恒定噪声。
因此在 `alignment_rules.NON_PAIR_WORK_IDS` 里按「非同一形态」跳过配对；**中文侧仍照常做单侧模板检查**
（已在报告中出现 `中 | S5_02_03 | …_Main.xhtml` 行）。

### `S5_03_02-08`：后记 `<br/>` 边界按日文侧对齐（已修订）

两侧都是 25 行，独占 `<br/>` 各 7 个，但分布不同。按**段落边界**（而不是行号）对照，
两侧 12 个段落一一对应，差异只在两处：

| 段落（1 起） | 日文 `段后 <br/>` | 中文（修订前） | 中文（修订后） |
| ---: | ---: | ---: | ---: |
| 1–6 | 0 / 0 / 2 / 1 / 0 / 0 | 同 | 同 |
| **7** | **2** | 1 ← | 2 |
| **8** | **0** | 1 ← | 0 |
| 9–12 | 1 / 1 / 0 / 0 | 同 | 同 |

对应到内容：段 6 = 「……顺便说一下，因为食蜂『在精神系方面无所不能』……」，
段 7 = 「另外，如果您是在某种机缘巧合下偶然闯入了『某系列』的世界……」，
段 8 = 「非常感谢担任作画的灰村先生……」。

即日文在段 6 与段 7 之间留了 2 个 `<br/>`（较大的视觉间隔），
中文误把它放在段 7 与段 8 之间。**按日文侧修正**后两侧独立 `<br/>` 行号一致：
`[9, 10, 12, 16, 17, 20, 22]`。

判定口径：`AGENTS.md`「中日两侧同一位置的换页标记与视觉间隔数量一致」。
两侧行数（25）与 `<br/>` 总数（7）都相同，`fix_legacy_pagebreak_br.py`（只在中文多出时删）
与「日文 h2 前后只删等于行数差的数量」两条机械规则都不适用，因此用一次性脚本按
段落边界搬移，不增删行、不改段落文本。

**修订方式**（不手算行号，让脚本自己对照日文侧）：解析两侧「段落 → 其后独占 `<br/>` 数量」序列 →
核对段数相同且每段是单块 `<p>…</p>` → 取日文序列为目标重建中文的 `<br/>` → 预检
（行数不变、`<br/>` 总数不变、非 `<br/>` 行按原序逐个不变）不过则不写盘。

`git diff` 结果只有 2 处增删，且都是 `<br/>` 行；段落文本逐字未变。
修订后 `check_alignment.py` 全库 **0 问题**（1105 个配对文件），
`check_epub_health.py --strict` 0 问题，`text_norm.py` 幂等 0 命中，
`publish_auto.py` 已回流 OneDrive 与缓存，`EPUB/` 与中文缓存逐字节一致 2720 / 0。

## 例外机制

新增 `alignment_rules.PAIR_RULES`（表头 → 规则名）与 `check_alignment.apply_pair_rules`：

- 规则命中后**只抵消该规则解释得了的问题项**，其余差异照报——不是整表头豁免；
- `afterword-moved` 必须完全解释掉行数差异（截断后行数相等 **且** `<br/>` 位置一致）才生效；
- `section-order` 必须是通过「行类型序列」验证的**纯互换**（`h2` 数、图片行数相同，
  类型序列除该处外逐行一致）才生效；
- 命中时报告里留一行备注说明依据，便于复核。

`TEMPLATE_EXEMPT_WORK_IDS`（`S0_00`、`S6_10.06.26`、`S6_24.12.10`，只豁免模板项）从
`check_epub_health.py` 移到 `alignment_rules.py`，两个工具共用一份——此前各存一份必然漂移。
