# 创约2「アワビ」双关译法修正与译注补录（2026-09-15）

## 判定口径

日文原文（`.cache/epub-work/japanese-text/[S3_02]創約 とある魔術の禁書目録(02)/item/xhtml/S3_02-03.xhtml` 第 262、264 行）：

- 御坂10032号：「大丈夫、このようにあわビキニで完全にガードしております」
- 御坂美琴：「お願いだからアワビだけはやめろ!!　言い回しがエグ過ぎるわ!!」

前句说的是「あわビキニ」，后句美琴抓住其中所含的「あわビ」＝「アワビ（鲍鱼）」这个谐音吐槽；后句写的是**被听出来的那个词**，不是前句的原词。

原译把后句写成「唯独『泡沫比』千万别提啦」，等于让美琴重复前句原词，谐音关系与「这种说法太露骨」的依据都丢了。因此把后句改成被听出来的词，再用译注补上谐音来源。
