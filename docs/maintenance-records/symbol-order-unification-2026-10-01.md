## 本次修改的判定依据

> 留档只忠实反映本次修改内容；**翻译方案以 `docs/translation-name-rulings.md` 的裁定为准**，本节只记本次为何这样改，不重复登记方案。

符号体台词（角色以符号替代假名并配 ruby 注音）是「符号替换 + ruby 注音」的刻意书写特征。用户提供了该符号体系的**权威对照表**，其中：

| 符号 | 振假名 | 含义 |
| --- | --- | --- |
| `〼` | ます／まし | ≈ do（肯定） |
| **`〼×`** | **ません** | **≈ don't（否定）** |
| `×` | ない／なく／ず／こと／ダメ … | 否定／转折 |
| `◎` | ある／よい／ぜったい … | 肯定 |
| `～` | から | 从 |
| `〆` | しめ | 弄紧、关闭 |

**关键**：`〼×` 是照日文的**整体记号**（ません），**不按中文读音重排**；中文侧沿用同一符号串。据此，全库中文侧 `×〼` 一律改为 `〼×`。

> **角色归属（2026-10-01 订正）**：符号体是**安娜·金斯福德**（`アンナ＝キングスフォード`，Anna Kingsford，首出**创约 卷6**）的说话特征——魔禁维基载其「说出来话变得有点奇怪……**还用各种各样的符号作为原本话语的注音**」，并列出创约06／07／08 的符号↔振假名对照表。**CRC 指克里斯蒂安·罗森克鲁兹**（`クリスチャン＝ローゼンクロイツ`，Christian Rosencreutz，蔷薇十字创始人，首出**新约 卷12**），是**另一个角色**（`S3_11-04` 中金斯福德称对方为「CRC」，旁白随即点明那是罗森克鲁兹）。
>
> 本记录与同批提交信息原先把两者等同（写作「安娜·金斯福德（CRC）」），**已订正为通称「符号体台词」**，不把符号体绑定到单一角色。
