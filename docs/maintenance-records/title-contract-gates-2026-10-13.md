## 工具与 CI

- title_rules.py 集中中文标题样式、分层、目录投影和文本分流合同；
  XML 底字提取复用 xhtml_text.py，支持命名空间，不把 rt/rp 拼进目录。
- check_epub_health.py 新增 error 级 title-style、title-catalog；
  本地 publish_preflight.py 和 CI 发布预检通过 audit_book 共用判定。
- NOTE_H1 更新后，两个译注生成器共用默认标题；彩页生成器补“彩页”，
  导入包装入口和 docx 成品入口在写盘前验证标题合同。
- check_translation_table.py 分开收集正文与 h1/h2/h3；
  标题不满足正文落地命中、不参与 strict。另写 translation-title-check.tsv，
  主 JSON 的 title_records 与 Markdown 人工核对节同时展示标题命中。
- 术语统一 skill 引用标题语言边界，普通正文映射排除标题。
  此处按 writing-for-agents 的单一来源原则维护指针，不复制完整判据。
- 现有体检 workflow 的 PR／主分支路径触发覆盖相关 yml；
  发布和自动规范化后的共享预检执行只读标题门禁，没有新增标题自动修复。
  工作流变动尚未推送，未在 GitHub 远端执行，也未修改分支保护。

本合同不维护逐标题预期层数，不能自动发现合法二层退回合法单层；
不判定标题译法或原始章扉层次。未知结构／样式先阻断、人工确认。
非标题锚点和无标题页面的目录标签保留，跳转由资源／锚点门禁检查。
