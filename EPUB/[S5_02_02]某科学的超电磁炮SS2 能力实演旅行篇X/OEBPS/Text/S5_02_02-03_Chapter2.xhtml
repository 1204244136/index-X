第二章

1

「跑掉了吗……」

「保安员」的一员，艾妮莉亚·G.艾尔格斯卡娅一边望着监视屏，一边叹了口气。

这是一间小小的房间。

那是位于审讯室隔壁、特殊镜子另一侧的房间。

先稍稍将她逼入困境，再刻意给了她一定程度的行动自由。让她能连接半公开型AR也好，没有删除她的账户也好，都是为了这个目的。本来还想着，如果失去冷静的美琴在网上和谁联络，说不定就会从中露出破绽……

艾妮莉亚的同事一边在墙上调出文件，一边这样说道。

「似乎是顺着窗户外的墙壁逃走了呢。墙面的AR用显示器因为磁力产生了故障。果然，不应该考虑『对于未成年人的关照』之类的事吧。」

「我们对于能力者的拘留管制办法是不可能有任何头绪的吧。就算是丁点的情报，也没有公开。」

艾妮莉亚嘟哝道，声音听起来与面对美琴时的口吻截然不同。

「……或者说，要用跟断头台一样的木质手铐拷上么。」

「那是个能用磁力转动螺栓的家伙啊。也许能让铁制品高速振动，当成锯子来用呢。」

「根本就没有解决方案啊。而且，那个能把身边的铁做成锯子、子弹之类的危险家伙，正在街上四处逃窜。」

艾妮莉亚将胳膊肘撑在桌上，垂下了头的同时，向同事发问。

「追踪的情况如何？可能的逃往地点有哪些？」

「不清楚。监视设备也没有捕捉到。」

「这应该是没有死角的系统啊……半公开型AR账户怎么样了？使用状况如何？」

这个城市的AR系统经过专门设计，会获取用户的位置信息，以防正在使用的影像服务被其他人窥视。若是反过来利用这一点，应该也能查出人的所在之处。

可是……

「从逃跑的时候起就完全没有使用过。而且现在也继续对其账户进行着监视……」

「对方也察觉到这个『特性』了呢。」

虽然看似失去了线索，艾妮莉亚却微微一笑。

「反过来说，那里才是突破口。」

「？」

「这个街道上的所有人，都在使用半公开型AR。即使没有强制这么做，不使用的话也会非常不便……在这样的人群中，只要有一个人没使用服务就会非常显眼。排查出『反应迟钝的家伙』。不光是街道的监视设备。现在，向在外巡逻的『保安员』下达通知。肉眼的监视有多重要，看看机场的可疑物品检查㊟就谁都明白了。」

瞥了一眼用墙壁上的AR进行联络的同事，艾妮莉亚静静地如补充说明似的继续思考。

（……那个能力者，在审讯室大喊了什么？）

操作着从AR系统中独立出来的显示器，她眯起了眼。

（……事件还没有结束。还剩下19个橙子。）

用手指敲击这桌面，用AR系统在表面显示出了搜查资料。

（……关于傍晚据称被嫌疑人「扣住」的水桶里的东西，详情尚不明确。由于基本已经炭化，甚至连是不是涉案的红巨足军队蚁都无法确定。）

鉴识人员正在调查DNA信息，今后也许会有什么新发现，但这大概需要花上相当长的时间吧。

当然，也不能排除那个「碳化的残骸」并非红大脚行军蚁的可能性。也就是说，这一切全都是初中生的恶作剧。

但是……

（要真是这样，把事情发展成从审讯室逃走这样的大事，是没有必要的吧？虽然惹了麻烦，但在那时除了「无危险性的蚂蚁」以外什么都没使用的话，问题本应该只是低头认错就能解决的。）

这么说来，难道真的正在发生光凭那样根本无法收场的严重事态吗？

（不过，从审讯室「逃走」那一刻起，最合情合理的恶作剧推论似乎就站不住脚了。事件确凿无疑。可眼下正在发生的究竟是什么事件？真的是红大足军队蚁，还是说如此主张的那个家伙打算引发另一起事件？）

艾妮莉亚思忖片刻，用食指指尖嗒地敲击桌面，挥开了AR的搜查资料。

（不管怎样，抓住她。）

她再次确认了自己的目标。

（从知情者身上寻找情报是最快的。）

2

日期已经换了一天。

御坂美琴在深夜的购物中心奔跑着。

白昼与黑夜截然不同，完全被区分开来。营业至夜晚的夜间休闲区灯火辉煌，持续散发出耀眼光芒。相对地，日落便结束营业的区域则一切光亮尽散，被黑暗所笼罩。

这空无一人的黑暗，也许跟夜晚的学校非常相似。

通往紧急出口与「保安员」值班室的路线，以及灭火器和AED的位置等，都用不同颜色的箭头在地面上标示出来。天花板上等距分布的蓝色光点，大概是自动喷淋装置的设置情况吧。

半公开型AR，就是这么个东西。

因为对面的传感器没有捕捉到美琴的身体（是她刻意诱导成这样的），所以应该无法针对个人进行聚焦。恐怕这些显示画面的隔离等级被设为了「全员公开化」吧。也就是说跟普通的电视一样。

藏身于摆满各类家电的陈列架中，等那几串脚步声走过去。

对手似乎三人一组行动着。好像运用着半公开型AR系统，追踪着在地面留下的「足迹」。

如果不是美琴对传感器动了手脚，转眼间就会被逼入绝境了吧。

（……反过来说，如果能对电子设备动手脚的话，也就意味着想怎么扰乱对手都行了呢。）

循着诱饵的「足迹」，「保安员」们朝着错误的方向跑去。美琴确认了这一事实。话虽如此，他们很快也会察觉到「足迹」的不自然吧。等他们不再依赖传感器之后，才是真正的较量。

不可以在这里被抓到。

此时此刻，藏有军队蚁之卵的橙子作为「生化炸弹」已经混进了这个购物中心，不知什么时候会引发集体孵化、极度活跃的大爆发。不知道这种蚂蚁有多顽强，可一旦散落四处，谁知道它们会潜伏在什么地方袭击人类。光是想想就让人害怕。

「……」

需要调查的事情各式各样。

来到这条街上后，已经听到过好几次「橙子」这个词了。除了一个一个去重新求证以外别无他法。

（……如果能使用AR系统的话就好办了。）

美琴保持着将身体藏在陈列架后的姿势，眼睛看向地板。

她是操纵电气的能力者。而且她不仅能产生强大的高压电流，连精密的黑客入侵等操作也能办到。在这座人与物的流动被如此高度管理的城市里，哪怕仅仅追踪监控摄像头与电子货币等的动向，要查明目标人物的藏身之处也绝非难事。对美琴来说，反倒是缺乏数字化的老式乡下小镇更不好办。

话虽如此。

这半公开型AR，交互界面需要『美琴这一肉体的动作』。也就是说，要是像平时那样活用超声波传感器，就会被追查她行踪的『保安员』发现。

要想使用它，就需要另一个账号。

虽然现在也用黑客手段蒙骗摄像头和传感器，但这个问题迟早会浮出水面。哪怕只是完全不用人人都在用的半公开型AR就这么生活下去，在肉眼看来也会显得格格不入吧。

为了能安全地将行动进行下去，果然还是想要一个新的账户啊。

但是，即使是能用能力进行黑客行为的美琴，无论何时何地都能准备好新账户这种事也是办不到的，这里的安保系统也不是不堪一击。

要想创建一个新账户，似乎有必要在物理上接近一台集中处理大量信息的大型服务器。

（首先，为了自身的安全与便利，就从那方面的准备开始吧。）

由于无法使用半公开型AR，美琴在脑海中强行回忆起记忆里的向导板。

环视周围一圈后，将视线固定在漏出薄薄光线的方向。

3

虽然都叫夜总会，但是形式上却有各种各样的不同。

在大量灯光的烘托下，呈现出与白天不同面貌的游乐园。充斥着铺天盖地的音乐与酒精，面向年轻人的俱乐部。以礼服与品行作为入场条件的歌剧剧场。在这片用灯光将夜晚的黑暗填满的区域中，提供着种类、档次与受众各异的娱乐。

虽然如此，能够满足美琴所寻求条件的地方十分有限。

设置了大型服务器，用于传输与其他区域根本不可同日而语的海量数据的地方。

「赌场吗。」

（……不过我还是更熟悉游戏中心啊。）

嘴上和心里都在嘟哝的美琴，现在并没有身穿常盘台中学的制服。她身上穿着一袭以红色为基调的晚礼服。那是她来到这里之前，从途经的礼服定制店深处翻出来的。上面写着「御坂美琴·公开表演专用服」，所以大概没问题吧。

鼓足气势赶来的美琴，实际踏入赌场后却发现，这里并没有充满那么正式而庄严的气氛。在有荷官的轮盘和百家乐㊟等赌桌旁，确实有许多身着礼服的绅士淑女；另一方面，在排满无需荷官的老虎机的一角，穿着T恤和牛仔裤的东方人也不在少数。这么一看，充其量就像是在玩稍微豪华一点的老虎机罢了。

另外，虽然不知道俄罗斯的法律是如何规定的，但至少在这家购物中心里，不分大人还是小孩，都在赌场大厅里来来往往。虽说大多是跟在父母身后，但这并不是因为有什么必须由大人陪同的硬性规定；说到底，游客本就是全家出行，孩子自然是跟着家里人结伴而来的，原因大概就在这里吧。

也正是因此，

初中生的御坂美琴在赌场内闲庭信步也不是那么惹眼。

不如说大家都习惯这样了吧。

（……那难道是值得自豪的事吗？）

周围与监视摄像机和传感器不同，有着许多「无法被能力欺骗的肉眼视线」。话虽如此，现在的美琴倒也没有被当成通缉犯当场指认出来，「保安员」也并未闻讯赶来。

也许是因为换上一身礼服让气质大变，也许是「保安员」对大众隐瞒了美琴的情报，又或者是太过习惯半公开型AR的人们，只要美琴头顶没有显示出「危险」图标，便连向她投去注视都做不到了？

只要能在被逼入绝境之前达成目标，怎样都行。

要是不趁还能行动的时候先采取行动，转眼间就会陷入困境。

（那么，）

美琴扫视四周。

（筹码都在这么哗啦啦地大笔增减。不光是现金，应该也有一套直接把信用卡数据换成筹码的机制。如果说没有连接世界各地信用卡公司的大型服务器，那肯定是骗人的吧。）

话虽这么说，因为赌场的内部装潢采用的是贵族豪宅风格，像大楼用空调室外机那样笨重方正的设备，应该不会就那么大模大样地摆在明处吧。极有可能是悄悄存放在地下室或是别的房间等某个地方。

墙壁、柱子、地板、桌子、展示窗。虽说这条街上到处都设有半公开型AR终端，但它们终究只是末端而已。想从那里触及控制账户的管理电脑，距离还远得很。单纯是因为途中的过滤器数量太多，能通过的信息受到了限制。

但是，只要从大型服务器直接发出指令，虽然多少有些硬来，却也能一口气突破防御。

美琴一边从身份不明的兔女郎那里接过一杯名为无酒精鸡尾酒的混合果汁，一边轻轻环视四周。

大厅深处是楼梯，二楼似乎设有VIP席。

换句话说，那里的正下方整体形成了一个巨大的矩形空间。

「在那里吗？」

将鸡尾酒酒杯轻轻地贴在唇边，美琴踏着不与人潮和室内音乐相违背的步调，朝着VIP特席的方向走近。

VIP特席的正下方是扑克牌的游戏桌。

牌本身由真人发牌人发放，至于筹码的下注与赔付，整张桌面似乎都成了半公开型AR，以数字化方式提供支持。

由于发牌人背靠墙壁，到底还是很难贴在墙上。

旁观玩家倒是随你的便，但要是总在后面转来转去，恐怕会被扣上「偷看牌给其他玩家通风报信」等莫须有的嫌疑。

要想迅速且长时间地贴着墙边，

（啊……果然，除了参加别无他法了吗？）

但是，这里的扑克。游戏本身（大概是为了保证公平性）配备了发牌员并使用纸质扑克，但在下注与筹码分配方面采用的则是半公开型AR系统。

不能使用自己账户的美琴，究竟能不能参加啊？

「嘻嘻嘻。您似乎很困扰呢？」

「哇？！」

突然从背后被招呼的美琴，肩膀因为惊讶而震了一下。

站在那里的是神秘商店的店员，蕾莎。不知为何，身着黑色兔女郎装的少女，手中银色的托盘上堆积了如山般各色的筹码。

「虽然不知到底因为何事困扰。难道是零花钱不够了吗？」

「稍微等一下。你之前在谈『橙子』的事吧。先让我仔细听听……」

话说到一半时，蕾莎刷地伸出了食指。

她把食指指腹贴在了美琴的下嘴唇上。

「NONO。在这里谈论这样的话题真的好吗？」

「（……你这家伙，等会儿好好抽空跟我谈谈啊。）」

这个名叫蕾莎的少女也是个来历不明的人。从她那里得到了关于「橙子」的线索。借此总算勉强应对了第一个橙子的爆炸。不过，目前还看不出蕾莎是好是坏。她与这起事件脱不了干系，这一点是毋庸置疑的。

可是，没有一个可以完全信赖的盟友，这一点也是事实。

不必抱有太高的期望。

（要利用所有可以利用之物，是吗？）

美琴确认了自己的方针。

（这样一来，果然还是按照原定计划，为了能在设施内自由走动，努力去获取一个新的账户吗？）

「你现在在工作？还是说穿成这样在这里玩？」

「幸运和必胜的纪念品店玛古罗希罗伊，正是在这种地方才能发挥真正的价值。平时总觉得可疑的那帮家伙，这会儿真是一个接一个地凑了过来。哎呀，我可不觉得会有能扭曲概率论和统计学的施术者呢。姑且先回答你的问题吧，我并不是赌场的店员，所以并没有被特别禁止在工作中赌博哦。」

「当然，半公开型AR是可以用的吧？」

「那是什么？」

对于蕾莎的疑问，美琴用大拇指指向一旁打扑克的桌子，说道。

「我会让你大赚一笔的，所以你得协助我。」

4

要说结论，那根本称不上是一场较量。

身穿黑色兔女郎装的蕾莎坐在扇状桌子的一角，美琴则在一旁就位，视线越过她的肩头窥探手牌。

之后只要根据发下来的五张牌，美琴稍作指示便足以应付。

顺便一提。

无论是拥有恐怖强运的人，还是经验丰富的职业玩家，都不可能百战百胜。这类卡牌游戏所需要的，是在最初阶段就明确看清能赢的对局与赢不了的对局。以最小的代价控制败局，以最大的收益锁定胜局。通过拉大这一落差，玩家最终便能赢得胜利与现金。

「哎呀，要是简单到这种地步，可真容易让人产生错觉呢。总觉得就像是得到了一个怎么花里面的钱都不会减少的存钱罐似的。」

「运气呀，技术什么的都是浮云。懂得数学的话谁都可以赢。」

「但是扑克不光是概率学与统计学的问题吧。我觉得，不如说心理战才是真正的乐趣所在呢。」

「经济学基本上就是研究心理活动的学问啦。市场上一旦蔓延开不安情绪，股价就会莫名其妙地暴跌，对吧？是跟进赌一把还是收手弃牌的博弈，道理也和那个一样。最难的反倒是根本没法博弈的代币游戏吧。」

美琴随口应付着，但她的目的并不是在纸牌游戏中取得胜利。

那边只是顺带应付。

真正的任务是利用在大脑中产生的细微电流对大型服务器进行黑客行为。

「但是这样好吗？」

「什么事？」

「不论玩多少次多少回，就算发牌人故意使坏，筹码也完全不见减少，搞得其他客人都烦躁起来，发牌人慌得手忙脚乱，再加上眼看差不多都要因涉嫌出千叫来『保安员』了，就是这种气氛啊。」

「这样太醒目了吗……再说，你知道我现在正被人追捕的事情吗？」

「一定程度上吧。」

「我现在想干什么也知道？」

「想赚点逃跑资金之类的吧？」

「开什么玩笑。逃跑可不是我的兴趣。」

吵闹声从美琴的身后响起。就如海浪一般，一点点朝她的方向接近。与其说是吵闹的人群在靠近，倒不如说是有人正拨开人潮走来的势头。

「是时候了吗？」

「该怎么办？要逃跑的话，我建议合法地引发一些混乱。例如把这堆筹码往正上方一扔，来一个樱吹雪之类的。」

（……不论是引起混乱还是别的什么，慌慌张张地逃跑这样的构图就太不妙了。怎么说也过于显眼了。）

滋滋滋滋滋滋！！美琴的额头内侧传来一阵发麻的感觉。

继续对大型服务器进行干涉。

此时骚动声更加接近了。

拨开人潮走过来的是「保安员」吗？

「（……出现要求提供数字身份证的提示了，不启动半公开型AR的话会被怀疑的吧。话虽如此，当真出示自己的ID的话就出局咯。）」

「（烦死了，给我闭嘴。）」

Project Code EIC。

关于以经济效果为前提对群体心理施加影响。


这项Project正在本购物中心内试运行。其宗旨是通过控制从大众媒体的宣传推广，到包含网络与口碑的用户间信息交流等所有层面的商品信息，从心理层面对顾客施加适当的刺激。

就其性质而言，我们无法真正凭空催生出本不应存在的商品。

我们说到底也只专门从事一项业务——为已经存在的商品附加其原本之外的价值。

被赋予高出其本身价值的商品会产生稀有性，从而加快消费速度；相反，被赋予低于其本身价值的商品，消费速度则会放缓。

只要联想到极为常见的高级感或标签之类，理解起来就不难了。


让某件商品的销售额上升的被称为正方向行为，反之使其下降的则称为负方向行为。


利用这积极行为与消极行为，通过调整各种商品的消费速度，借此在市场中引发巨大的「趋势」。而支配整个经济圈本身，才正是这个Project的意义所在。


无论是正向行为还是负向行为，我们都以「已经存在的商品」为轴心附加各种信息，给出「具备自由度的强迫」。

他们便会用自己的头脑判断一件商品当前的价值，并预测其未来的价值。最终作出是否购买的选择。

如果预想降雨量过少导致水源枯竭的话，就会购入更多饮用水。另一方面，如果预想降雨过多会对农作物收成造成恶劣影响，就会购入更多的蔬菜。

如果预计会是暖冬，就会打算暂缓购买雪地轮胎。如果预计严寒会导致花粉量减少，就会考虑减少口罩的购买量。

即使，

其实这是基于毫无根据的数据所做出的预测，也是如此。


购买这些商品所需的判断材料数据，往往只优先考虑直觉上的可信度。从经专门机构高度验证的新闻报道，到四处漫溢的杂乱传言，各类层级的信息不加区分地被汇总在一起的情形很多。

我们以「流行」的形式，对指定商品实施正方向行为与负方向行为。

消费者们的心理会通过这些情报被控制。

虽然可以列举出多个信息来源，但重要的并不是具体哪一家媒体。

人们对多种媒体没有抵抗力。

对于被一家媒体盛赞，却被其他媒体否定的事物，人们就会在自己心中对其再三考量。

但是另一方面，比如在局部网络上流传的话题，一旦被电视等大众媒体报道，人们便会从中感受到信赖与保证之类的东西——这就是人之常情。

反过来利用顾客自身建立的信息判断思维回路本身，通过多种媒体阶段性地发布信息，我们便能向顾客注入所需的流行，售出目标商品，让目标店铺的目标销售额随之增减。

如果把这比作是金字塔，从地基起由下至上，以经过微调的振动来撼动顶点，就是我们的最终目的。


本购物中心内的实验，采取的是「谣言」这一形式。

我们发出的实验用情报，会在多长时间内扩散到什么程度，又会在多长时间内平息？还有，在扩散的过程中会被歪曲到什么程度？

在各年龄层的顾客中，实际以这些话题为基础「展开行动」的比率达到何种程度？

准备多条实验用情报的传播渠道，搜索出最合适的一条便是第一次实验的目的……
